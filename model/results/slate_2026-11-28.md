**Cover % (bet now)** is calibrated on 2022-26 DraftKings *opening* lines: a logistic fit of real outcomes on the model's edge (slope +0.0577 ± 0.0223 per point, n = 3,824). It is the right benchmark for betting an early line, but the backtest knew each game's absences, so it is optimistic. **Cover % (at close)** uses the closing-line fit (slope -0.0185 ± 0.0271, n = 5,117, floored at 0): once the line has absorbed the news the model has no measurable edge, so every side is ≈ 50%. **Raw model %** assumes the model is exactly right with normal errors (SD 14.1 pts) and overstates confidence; it is shown for reference only.

**Whale move** is the DraftKings line move toward that side that this season's Polymarket whale flow has historically preceded (1.96 pts per unit of whale share, t = 5.8). Whale flow did *not* predict covers against the closing line, so it is not in the cover %.
